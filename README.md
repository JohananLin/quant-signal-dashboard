# quant-signal-dashboard# 📈 量化信号看板 (Quant Signal Dashboard)

基于 Python + Streamlit 的 A 股量化策略信号看板，支持：
- **双均线策略**（MA5/MA20 金叉死叉买卖信号）
- **动量轮动策略**（每月调仓，持有动量最强的 2 只股票）

## 🚀 在线体验
👉 [点击打开看板](https://johananlin-quant-signal-dashboard.streamlit.app)（替换为你的真实 Streamlit Cloud URL）

## 📱 手机使用
打开上述链接，可在手机浏览器中直接查看，也可添加至主屏幕，体验接近原生 App。
